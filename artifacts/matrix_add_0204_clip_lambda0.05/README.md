# Canonical artifacts: `matrix_add_0204_clip_lambda0.05`

These are the saved outputs of the paper's add-k run on Llama-3-8B-Instruct
(coefficient-matrix training with coefficients clipped to [0,1] and L1 penalty
lambda = 0.05, seed 42). They let every downstream analysis stage run without
re-training. Large intermediate accuracy dumps (`matrix_acc_list*.pth`) and the
`savevars/` activation cache are intentionally not shipped.

## `args.json`

The complete argument record of the coefficient-matrix training run
(`subspaces.runners.train_matrix`): model name (`meta-llama/Meta-Llama-3-8B-Instruct`),
hook layer, seed (42), L1 penalty, batch size, epoch count, and the exact
in-distribution / OOD task-key splits. Downstream stages read it to reconstruct
the training configuration when interpreting the checkpoints. Note the recorded
`task_dir` value `number_add_1018` is the historical internal name of the task
family that ships as `dataset_files/number_add/` (the same 30 add-k tasks; the
alias is handled by `PROVENANCE_TASK_ALIASES` in `subspaces/step1/matrix.py`).

## `checkpoints/` (matrix_epoch47.pth ... matrix_epoch49.pth)

Per-epoch checkpoints of the trained head-coefficient matrix (one 32x32
layer-by-head tensor per file), pruned to the trailing three epochs (47-49)
of the original 50-epoch run — the window the checkpoint-selection rules
consume. `checkpoints/matrix_epoch49.pth` is the trained coefficient matrix
the paper uses: `subspaces.utils.heads.load_latest_matrix` globs `matrix_epoch*.pth`
and loads the highest-epoch file. All later stages (head selection, head
eval, PCA decomposition) start from this matrix.

## `head_ordered.jsonl`

Heads with significant learned coefficients, one JSON object per line
(`{"head position": [layer, head], "coefficient": ...}`), ordered as extracted
by the head-selection stage (`subspaces.runners.run_head_select`).
`subspaces.runners.verify_reproducibility` cross-checks the coefficient > 0.2 set
against this file.

## `head_acc_dict.pth`

Per-head single-head intervention accuracy cache produced by the legacy
per-head evaluation stage. It ships precomputed and is not regenerated by
the released runners (`subspaces.runners.run_head_eval` writes its per-head
accuracies to a JSONL instead). Read by
`subspaces.utils.heads.select_heads` (the `rank_by='accuracy'` path) and by
`subspaces.runners.verify_reproducibility` to reproduce the paper's main-heads set
without a GPU.

## `mod_vectors_dict.pth`

Ground-truth Section-4 fit results: for each main head, the fitted periodic
(cos/sin) plus magnitude direction vectors over the low-dimensional PCA
subspace. `subspaces.runners.run_pca_decomposition --compare-mod-vectors` validates a
fresh decomposition against this file (per-direction |cos| agreement).
